# TDD
 
## 🚀 Exécution du programme

### **1️⃣ Lancer le programme principal**
Le fichier `main.py` permet de résoudre le problème pour une taille `N` donnée par l'utilisateur.

```bash
python main.py
```

### **2️⃣ Lancer les tests**
Le fichier `test_runner.py` permet de lancer tout les tests.

```bash
python test_runner.py
```
